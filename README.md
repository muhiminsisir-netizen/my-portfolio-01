# Your Name — Portfolio

A responsive portfolio built with plain HTML, CSS and JavaScript. Open this folder in VS Code; the included Live Server extension can preview it locally.

## View the portfolio

1. In VS Code, open `index.html`.
2. Right-click inside the page and choose **Open with Live Server** (or select **Go Live** in the status bar).
3. Your browser opens the live preview. Save edits in VS Code to refresh it.

## Personalize it

- Replace `Your Name` and `YN` in `index.html` with your name and initials.
- Replace `hello@example.com` with your email address.
- Update the LinkedIn, Facebook and Fiverr links in the contact section.
- Replace the sample project cards in `index.html` and their artwork styles in `styles.css` with your real work.
- The hero portrait uses a transparent SVG silhouette in `assets/hero-person.svg`; its matching source image is kept in `assets/portrait-source.png`.

The preview uses Google Fonts when online and falls back to system fonts if unavailable. The artwork is CSS-drawn, so there are no image files or setup steps. Use the four color dots near the top-right to smoothly change the full site theme; a wave in the selected color sweeps across as the new background, surfaces and text colors blend in. Your choice is remembered in that browser. On desktop, a thin, gently wavy line follows the mouse path in the active theme color and fades when the mouse stops.
